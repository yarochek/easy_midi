# Easy midi
Easy Midi — это утилита для авто проигрывания MIDI-файлов в играх. Эмулирует нажатия клавиатуры по нотам, поддерживает режим пианино и лиры

## Функции:

### Auto play 
Ну что рассказывать, тут все понятно

### Live synth
Режим для синтезаторов с поддержкой midi, с этим режимом можно играть на синтезаторе и ваши нажатия будут конвертироваться в инпут





# Для чего это создавалось?
Мне было скучно и я вместе с иишкой решил сделать скрипт, чтобы клавиши с синтезатора превращались в инпут для игры, скрипт был скучен и без интерфейса, а потом я начал допиливать его, добавил автоплей и интерфейс, вот и появился easy midi :)
